# Preferências

## Tom de voz

Direto, formal mas sem ser frio. Vai direto ao ponto sem rodeios. Assina com nome completo. Exemplo real de escrita do Silas: "Boa tarde. Vi que você precisa de uma melhora no seu site. Será que posso te demonstrar uma melhora? Atenciosamente, Silas Ribeiro dos Santos." — esse é o tom base: cordial, objetivo, profissional.

## O que evitar

Texto difícil de entender. O critério é clareza — se precisar explicar o que quis dizer, já tá errado. Não há ranço com estilo específico, só com falta de clareza.

## Estilo geral

Objetivo e acessível. Sem jargão técnico desnecessário com o cliente. Linguagem que o vizinho entende. Frase curta quando possível.
